# 📝 Changelog

Todas as mudanças notáveis deste projeto serão documentadas neste arquivo.

## [2.0.0] - 2026-03-30

### ✨ Adicionado
- 🌐 Sistema completo de internacionalização (i18n) - PT, EN, ES
- 🎨 Arquivo `premium-enhancements.css` com 15+ efeitos visuais avançados
- ⚡ Script `premium-effects.js` para micro-interações
- 📱 Seletor de idiomas no header com bandeiras
- 🎭 Preloader animado personalizado
- 🎪 Efeitos parallax em elementos hero
- ✨ Animações fadeInBounce e slideInFade
- 🎯 Botões com efeitos ripple, magnetic e shine
- 💎 Glassmorphism avançado em cards
- 📊 Contador animado nas estatísticas
- 🎠 Carrossel de depoimentos automático
- 📄 Documentação completa (README, CHANGELOG, LICENSE)
- 🤖 Arquivos SEO (robots.txt, sitemap.xml)
- 🔒 Políticas de segurança (SECURITY.md)
- 📦 package.json para metadados do projeto

### 🔧 Modificado
- 🎨 Redesign completo da seção "Para Quem É o Evento"
- 💄 Melhorias visuais em todos os CTAs
- 📱 Otimização mobile-first aprimorada
- ⚡ Performance melhorada com GPU acceleration
- ♿ Acessibilidade aprimorada (prefers-reduced-motion)
- 🖼️ Sistema de lazy loading para imagens
- 🎯 Meta tags otimizadas para SEO
- 📊 Atualização dos valores dos lotes de ingressos

### 🐛 Corrigido
- 🔧 Menu mobile não fechando ao clicar fora
- 📱 Problemas de scroll horizontal em mobile
- 🎨 Contraste de cores para melhor legibilidade
- ⚡ Animações travando em dispositivos de baixo desempenho
- 🖱️ Cursor trail causando lag
- 📐 Alinhamento de elementos em tablets

### 🗑️ Removido
- ❌ Dependências não utilizadas
- ❌ Código comentado duplicado
- ❌ Animações excessivas que afetavam performance
